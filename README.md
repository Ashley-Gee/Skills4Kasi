# Skills4Kasi | Secured by FNB

Connecting Kasi Skills to Kasi Jobs - FNB App Academy Project

## Problem
Township talent exists but trust is missing. Clients fear losing money, providers fear not getting paid.

## Solution
Mobile marketplace with FNB eWallet Escrow:
- Client books → FNB HOLDS money
- Provider does job → Client confirms
- FNB RELEASES payment
